# knyte-space-search
Implementation of semantic search engine and markup tools for any type of content.

## Project layout

The project follows the official Zig project structure (as generated by `zig init`):

```
build.zig        - build script
build.zig.zon    - package manifest (name, version, fingerprint, dependencies)
src/main.zig     - CLI entry point (std.process.Init / std.Io based)
src/root.zig     - library module with the core logic and its tests
```

## Requirements

- [Zig](https://ziglang.org/download/) `0.16.0` or newer (see `minimum_zig_version` in `build.zig.zon`)

## Building

Build and install into `zig-out/bin`:

```sh
zig build
```

The build script uses the standard target/optimize options, so cross-compiling
to any major platform works out of the box:

```sh
# macOS (arm64 or x86_64)
zig build -Dtarget=aarch64-macos
zig build -Dtarget=x86_64-macos

# Windows
zig build -Dtarget=x86_64-windows-gnu

# Linux
zig build -Dtarget=x86_64-linux-gnu
```

## Running

```sh
zig build run
```

or directly:

```sh
./zig-out/bin/knyte-space-search
```

## Testing

```sh
zig build test
```
